### 4. 守门 prompt 微调(#44,用户指令)

桶a(金块在上下文但 judge 低分)中可行动子类的对症修改:

- **prompt 两处**(RAGLITE_SYSTEM_PROMPT + SYSTEM_PROMPT 负证据守门)各加两条例外:
  - ①推导数值:所需数值可由资料参数按公式直接算出时不算"资料未涉及",
    应列出计算式、给出结果、注明参数出处(治 dev_143 型拒答);
  - ②查表前置:检索资料含表格时先逐行核对目标行/列,确认表格确无该项
    才能判"资料未涉及"(治 dev_157 型"未提及能量模式")。
- **忠实性红线**(RAGLITE)补豁免:推导计算结果视为有据支撑,但须列计算式+参数出处。
- **grounding 层1 豁免**(必须配套,否则 prompt 放行了校验层还是杀):
  `_layer1_check` 对含计算标记(`计算/推导/推算/换算/估算/公式/按…模型`)
  且句中含 ≥1 资料数字(运算对象有据)的句子不层1判死,交层2 LLM 按
  "直接推论"标准判;层2 判 true 仍需资料原文 quote 机械验证,幻觉风险可控。
  纯幻觉句、无据运算对象的计算句照杀。
- 验证:构造 3 句用例(计算句豁免/幻觉句杀/无据计算句杀)全部符合预期;
  test_grounding 与基线持平(10 passed,4 failed 为已知遗留)。
