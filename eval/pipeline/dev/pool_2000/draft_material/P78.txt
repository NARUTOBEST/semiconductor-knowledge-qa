===== [p112-112] Setting EGA Shots Automatically (2块) =====
--[p112]-- \~ How to Set the g-shots and t-shots Automatically \~
This procedure automatically sets g-shots and t-shots.
Ideally, EGA shots are placed at the outermost edges of the shot array, at the vertices of a regular polygon. Thus, when EGA shots (either g-shots or t-shots) are automatically set, the system calculates a polygon that is as large as possible, and that has exactly the same number of vertices as the number of shots specified by the operator.
--[p112]-- The shot closest to the vertex is selected as the EGA shot (NOTE) .
If EGA shots are automatically set, previously specified EGA shots of the same type will be canceled.

===== [p285-285] 2.1 WAFER PREALIGNMENT ADJUSTMENT VALUES > 2.2 WAFER COORDINATE ADJUSTMENT VALUES (3块) =====
--[p285]-- The shot exposure position is designed in of the wafer coordinate system.
When exposure processing is carried out on multiple NSRs, differences in wafer coordinate system settings between individual machines lead to variations in shot position on the first exposure, and then to the generation of search alignment errors on the second exposure.
The wafer coordinate adjustment value specifies values which are used for coordinates conversion of the shot design position.
--[p285]-- Using these values makes it possible to adjust the shot position to the condition of shots exposed on the master machine used for reference. By performing the same adjustment process on all machines used together in the exposure process, differences in wafer stage control between the said machines can be reduced.
The wafer coordinate adjustment value is one of the factors making up the adjustment function which realizes adjustment of the wafer coordinates.
--[p285]-- This adjustment function is considered as the initial function acting to correct the wafer coordinates. In more advanced steps of the wafer alignment process (search alignment and EGA), it is replaced by a correction function with higher precision.
The functioning of this parameter differs in the 1st exposure and the 2nd exposure.
